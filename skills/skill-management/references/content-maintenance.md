# Content maintenance

Read the current source and relevant references before editing. Protect existing changes. Keep descriptions focused on the action and trigger. Put long workflows in references and preserve necessary precision and authorization boundaries.

Validate frontmatter, relative resources, and representative positive and negative routing cases. Use `local-agent-manager skills audit --repo-root <source>` for a requested source audit. Static `sourceAudit.sharedResourceReferences` may permit exact cross-Skill resources within that source. Shared resources remain owned by their original Skill.

Dependency changes require the source's documented runtime checks. Pure prose changes need a diff and affected-reference review. Existing direct mounts reflect source edits, and client refresh follows that client's supported behavior.
